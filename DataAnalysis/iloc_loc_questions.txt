================================================================================
PRACTICE TIPS
================================================================================

1. iloc uses INTEGER positions (0-indexed)
   - df.iloc[0] = first row
   - df.iloc[0, 0] = first row, first column
   - df.iloc[0:5] = first 5 rows

2. loc uses LABELS (row indices and column names)
   - df.loc[0] = row with index label 0
   - df.loc[0, 'salary'] = value at row 0, salary column
   - df.loc[df['department'] == 'IT'] = all IT employees

3. Key Differences:
   - iloc: df.iloc[0, 3] = row 0, 4th column (integer position)
   - loc: df.loc[0, 'salary'] = row 0, column named 'salary' (labels)

4. Slicing Behavior:
   - iloc[0:5] = rows 0,1,2,3,4 (end exclusive)
   - loc[0:5] = rows 0,1,2,3,4,5 (end inclusive for labels)
